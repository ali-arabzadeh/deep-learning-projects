# 🧠 Neural Networks

This directory contains foundational deep learning exercises completed during the AI Bootcamp.

The notebooks introduce the fundamental concepts of artificial neural networks, from implementing a perceptron from scratch to building and optimizing fully connected neural networks using TensorFlow and Keras for real-world classification tasks.

## Contents

| Notebook | Description |
|----------|-------------|
| `perceptron_from_scratch.ipynb` | Implementing the Perceptron algorithm from scratch to understand the fundamentals of neural networks. |
| `breast_cancer_classification.ipynb` | Building a fully connected neural network to classify breast tumors as benign or malignant. |
| `stroke_prediction.ipynb` | Predicting stroke occurrence using a deep neural network trained on healthcare data. |
| `neural_network_hyperparameter_tuning.ipynb` | Exploring the impact of hyperparameters on the performance of fully connected neural networks. |

## Topics Covered

- Artificial Neural Networks (ANN)
- Perceptron
- Forward & Backward Propagation
- Binary Classification
- Multi-class Classification
- Hyperparameter Tuning
- Model Training and Evaluation
- Deep Learning with Keras

## Libraries

- Python
- NumPy
- Pandas
- TensorFlow
- Keras
- Matplotlib

## Goal

The objective of these exercises is to build a solid understanding of neural network fundamentals and gain hands-on experience in designing, training, optimizing, and evaluating deep learning models using TensorFlow and Keras.
