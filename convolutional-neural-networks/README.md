# 🖼️ Convolutional Neural Networks

This directory contains Convolutional Neural Network (CNN) exercises completed during the AI Bootcamp.

The notebooks introduce the core concepts of CNNs and demonstrate how convolutional layers automatically learn hierarchical image features for computer vision tasks.

## Contents

| Notebook | Description |
|----------|-------------|
| `cnn_introduction.ipynb` | Introduction to Convolutional Neural Networks and image classification using TensorFlow and Keras. |

## Topics Covered

- Convolutional Neural Networks (CNN)
- Convolution Layers
- Pooling Layers
- Feature Extraction
- Image Classification
- Model Training
- Model Evaluation

## Libraries

- Python
- NumPy
- TensorFlow
- Keras
- Matplotlib

## Goal

The objective of these exercises is to build a strong foundation in convolutional neural networks and understand how CNN architectures are applied to image classification problems.
