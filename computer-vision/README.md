# 👁️ Computer Vision

This directory contains computer vision exercises completed during the AI Bootcamp.

The notebooks demonstrate classical computer vision techniques for analyzing images and videos using OpenCV. The projects focus on image preprocessing, feature extraction, segmentation, and object detection without relying on deep learning models.

## Contents

| Notebook | Description |
|----------|-------------|
| `lane_detection.ipynb` | Detecting road lane markings from video frames using classical computer vision techniques. |
| `apple_segmentation.ipynb` | Segmenting apples from images and estimating their count using image processing algorithms. |

## Topics Covered

- Image Processing
- Gaussian Blur
- Edge Detection
- Region of Interest (ROI)
- Hough Transform
- Image Segmentation
- Morphological Operations
- Watershed Algorithm
- Contour Detection
- Object Counting

## Libraries

- Python
- NumPy
- OpenCV
- Matplotlib

## Goal

The objective of these exercises is to develop practical computer vision skills by applying classical image processing techniques to real-world problems such as lane detection, image segmentation, and object analysis.
